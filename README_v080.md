# DUALORA v0.8.0 Gaming Diagnostics\n\nGaming diagnostics panel: shows current resolution/refresh, maximum reported display modes, and specific troubleshooting for gaming smoothness. Opens Windows Game Mode settings. VRR/G-Sync/FreeSync is explicitly **not verified** by this tool; check Windows, GPU drivers and monitor OSD. The tool does not overclock displays or promise higher rendered FPS. No automatic system setting changes are performed from this panel.\n
